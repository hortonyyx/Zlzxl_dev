# 需求池

## 现在(MVP:上课模式 + 学习模式)

- 库管理:库列表;新建学习库(多模态输入)。
- 上课模式:课堂录音(前台连续 + 分段)、课后转写、标记疑问、传课件。
- 课堂总结:三段式(完整总结 + 要点提炼 + 核心问题),立即固化。
- 知识点池:一等实体、稳定 ID、归一化、轻量 relatedIds。
- 学习模式:到期清单 → AI 编排学习节点 → 测验 / 闪卡 → 信号回写。
- 学习脉络:逐课迭代,三层呈现,delta 提示。
- 冷启动:demo 示例库 + 空库引导。

## 下一步

- 规划模式:AI 按显式目标编排未来一串学习节点与时间表。
- 完整 SRS / 遗忘曲线调度(在已存的信号时间序上接入)。
- 更多模块:语音抽背、听写。
- 用户在脉络上主动触发模块的入口。
- 测验语音作答;实时转写 + 课中 AI 旁注(呈现形式待定)。
- 知识点带类型双链与图感知复习编排。

## 之后

- 轻量合规上线(录音前提示、删除入口)与完整合规。
- 扩展到转型类考试、强练习课型、K12。
- 评估跨平台产品需求。
